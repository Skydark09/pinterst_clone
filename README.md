# Pinterest Clone

A simple Pinterest-inspired photo gallery built with HTML and CSS.

## Run locally

Open `index.html` in a web browser, or use VS Code Live Server to preview the
page locally.

## Project files

- `index.html` contains the page layout and photo cards.
- `style.css` contains the layout and hover styles.
- `assests/` contains the photos used in the gallery.
- `icon.svg` is the browser tab icon.
